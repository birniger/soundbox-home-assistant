# Changelog

## 0.2.0 — 2026-10-20

- Add Media browser folders for all stations, favourites, tags, cities, and
  radio modes, with separate folders for multiple connected accounts.
- Share speaker sessions between the Media browser, actions, and Assist so
  Next, Previous, More/Less and Save Song follow the selected station.
- Preserve radio modes during navigation; direct station playback continues
  in station-bank order, matching Alexa.
- Add an explicit, default-off option to share playback events and estimated
  listening seconds with Soundbox's mode-specific learner.
- Apply More/Less to the shared learned preferences rather than replacing the
  station's manual preference setting.
- Document the actual browse tree, playback lifecycle, listening option, and
  data sent to Soundbox in the README and Privacy section.
